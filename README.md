# employee-salary-analysis-powerbi
Employee Salary Analysis Dashboard using Power BI

## Overview
This repository contains a **Power BI Salary Dashboard** that provides insights into employee compensation and workforce demographics.  
The dashboard helps HR, finance, and operations teams analyze salary distribution across departments, education levels, cities, and experience.

## Features
- **Summary Metrics**
  - Total Salary: 4M
  - Maximum Salary: 149K
  - Minimum Salary: 28K
  - Average Salary: 82.29K

- **Visualizations**
  - Salary by Department (Marketing, Operations, HR, IT, Finance)
  - Employees by Gender (Male vs Female distribution)
  - Employee Count by Department
  - Experience vs Salary (scatter plot analysis)
  - Salary by Education (High School, Bachelor, Master, PhD)
  - Salary by City (Bangalore, Delhi, Mumbai, Hyderabad, Chennai)

## Insights
- Marketing has the highest average salary (96.48K).
- Finance shows the lowest average salary (67.28K).
- Gender distribution is balanced: 54% Male, 46% Female.
- Salaries increase with experience, but vary across departments.
- Higher education levels (Master/PhD) correlate with higher salaries.

## Tech Stack
- **Power BI** for data visualization
- **Excel/CSV** as data source (can be adapted to SQL/other databases)
- **Data Modeling**: relationships between employee demographics and salary
